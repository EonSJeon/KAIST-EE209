assignments 아래 있는 폴더, 파일만 건들 것
subfolder 이름을 "# 프로젝트 이름"으로 바꿀 것.
#는 숙제 번호, 프로젝트 이름은 pdf에서 읽어서 바꿀 것
venv를 설정해서 assignments, precepts 모두 compiles 및 execute 가능하게 할 것
모든 assignment는 한번에 실행할 수 있게 각각 sh가 있어야 함
현재 있는 것은 내가 예전에 한 건데 엄청 틀렸을 것임(특히 마지막 과제)

각 과제 폴더에는 old와 corrected 서브폴더가 있어야 함
old 서브폴더에는 본래 했던 과제를 보전하는데 
왜 틀렸는지 어떤 습관이 잘못됐고 어떤 개념이 부족한지 각 과제마다 아예 코트 자체에 코멘트 달아주고 review를 md로 만들어줘
corrected 서브 폴더에는 최대한 내 이전 버전이랑 유사하게 하면서 숙제를 완료할 수 있게 변경
여기에 .sh 파일이 있어야 하는 것
